A news app built with Flutter that fetches and displays the latest headlines from a REST API.

---

## 📱 Features

| Area | Description |
|---|---|
| **Latest News** | Fetches up-to-date headlines from a news API |
| **REST Integration** | Parses JSON responses and renders them in the UI |
| **Simple UI** | Clean Material design focused on readability |

## 🛠️ Tech Stack

| Category | Technology |
|---|---|
| Framework | Flutter |
| Language | Dart |
| Networking | `http` |
| Built with | [FlutLab](https://flutlab.io) — Flutter Online IDE |

## Getting Started

```bash
# Clone the repository
git clone https://github.com/22ousefmostafa/newsapp.git
cd newsapp

# Install dependencies
flutter pub get

# Run the app
flutter run
```
